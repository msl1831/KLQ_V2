# 超声波经主机 USB 升级实测（2026-10-29）

## 结果

**正常升级流程通过。** 使用当前生产PC工具 `codex/python-runtime@60a5f04`，从主机USB（COM123）经端口2完整重写UL应用1.0.2，耗时 **3.328秒**。升级前后应用均为1.0.2，这是同版本全量重写验证，不是版本号变化证明。主机仍为0.9。

## 升级证据

- APP INFO为1.0.2；ENTER、HOLD及引导INFO均成功，引导实际报告1.0.2，与最新SWD安装记录相符。
- 最新PC工具在BEGIN前检查引导至少1.0.2，板型/硬件兼容号、UID和分区布局一致后才允许擦写。
- BEGIN返回偏移0；**46个DATA包、5832字节**，45包128字节、末包72字节，每个ACK偏移正确。
- 用日志中46包请求重建APP，与冻结的应用包逐字节一致，CRC32为`A20B01FE`。END整镜像CRC校验成功，RUN明确收到成功ACK。
- 同UID重新报告APP模式/版本1.0.2；CLOSE确认成功，主机INFO及ECHO通过，待机`UI=1`、`USER_STATE=0`、`PY_ERROR=0`。
- 共57条外接命令记录，全部成功。本轮只通过USB协议写P2应用区和元数据，没有使用SWD。

完整请求/应答、源码及制品哈希见[机器记录](ul_via_host_20261029.json)。原始日志位于本机`build/ul_via_host_20261029/upgrade.json`和`upgrade.log`。
