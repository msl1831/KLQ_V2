# SC7A20HTR 与串口实板验证

日期：2026-09-14
目标板：APM32E103RET6，外部 16 MHz 晶振
连接：DAPLink `LU_2022_8888`，机器人 USB CDC COM123

实测应用：12,168 字节，SHA-256 `c169aab7be12963a898d5e7ba6e526beefb463a086a15cf3c8ac4e4e180b78d0`。

## 实现范围

- SC7A20HTR 使用 PB8/PB9 软件 I²C，包含时钟拉伸超时、总线九脉冲恢复和 0x19/0x18 地址探测。
- 传感器配置为 100 Hz、±2 g、12 位高分辨率、块数据更新，输出 X/Y/Z 毫 g 和由重力向量计算的 Roll/Pitch。
- USART1、USART2、USART3、UART4、UART5 均初始化为 115200、8N1、无硬件流控；UART4 保留给内置音频模块，尚未实现音频协议。
- USB CDC 以约 10 Hz 输出传感器数据。`tools/serial_monitor.py` 自动识别 KLQ VID/PID，断线后自动重连。

## 实测结果

- 识别到 SC7A20HTR 地址 0x19，WHO_AM_I=0x11，版本寄存器=0x28。
- 两次不同放置姿态均持续输出有效值。一次静置样本约为 X=64 mg、Y=35 mg、Z=1033 mg、Roll=1.94°、Pitch=-3.54°；另一次放置约为 X=267 mg、Y=-196 mg、Z=973 mg、Roll=-11.38°、Pitch=-15.05°。
- DAPLink 读回串口寄存器：USART1 BRR=0x271；USART2、USART3、UART4、UART5 BRR=0x138；五路 CTRL1 均为 0x200C。结合 72 MHz PCLK2 和 36 MHz PCLK1，对应 115200、8N1、收发使能。
- 引导协议 26 组边界回显、重复包、坏 CRC、越界请求及错误后恢复通过。
- 应用分区中断下载保护、错误整包 CRC 拒绝、完整下载校验、应用 USB 回显和复位返回引导通过。

## 当前限制

- Roll/Pitch 使用未经校准的芯片原始坐标；板级安装方向、零偏和滤波尚未确定。
- 三轴加速度只能在静止或低动态时估算倾角；快速运动会改变结果，且不能提供航向角。
- UART 目前只完成引脚、波特率和收发器初始化，尚无接收缓冲、外设协议或音频命令。
