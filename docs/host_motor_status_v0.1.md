# 普通电机只读USB快照 V0.1（主机0.13起）

可选工程观测接口；正常上位机积木仍生成python_api_v0.1.md中的函数，下载流程不变。INFO包含EXT_MOTOR_STATUS=1才轮询。旧固件无能力位不发该命令；若返回ERR_COMMAND，本连接禁用查询，不以0冒充数据。

命令0x55，请求payload空。沿用KLQ1头/CRC/序号，响应payload先4B标准状态码，成功后19B：

| 偏移 | 类型 | 含义 |
|---:|---|---|
| 0 | u8 | ABI=1 |
| 1+6*i | u8 | 状态，i=0/1/2对应P1/P2/P3 |
| 2+6*i | u8 | 端口缓存online，0/1 |
| 3+6*i | i16LE | 普通驱动目标PWM，-1000..1000 |
| 5+6*i | i16LE | 最近UART ACK PWM，-1000..1000 |

状态0空闲、1待确认、2活动、3停止中、4故障。online表示端口缓存，传感器口也可能online；结合端口class2/type2判断电机。该命令只读已有缓存，不发新的UART、不停止电机、不改变诊断/升级token；运行/下载/诊断/关机等待期间允许读。诊断占用口可能已解绑，不能用此时缓存0判断实际输出。

lastACK不是物理速度或引脚电平；离线、过期或故障时不要把缓存0当作停机证明。软件板测应在未进入diagnostic前观察普通ACTIVE→STOPPING/IDLE与ACK归零，实际转动仍看实物。页面通过同一个CDC worker查询，目标/ACK/阶段过期2s则改未知；不额外开串口。工具入口test_python_motor_live.py，自动工具会主动清理临时RAM；用户手动重复观察则使用保留在RAM的示例和正常监测，不依赖自动工具60s窗口。
