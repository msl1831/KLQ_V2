# 26 个非语音积木的模拟与实板接口测试（2026-10-14）

固件源码基线为 `94435d1`、系统固件 `KLQ ROBOT FW 0.8`。本轮增加测试工具和报告，未修改生产固件源码，也未擦写主机内部 Flash。完整记录：[宿主模拟 JSON](blocks_sim_20261014.json)、[实板接口 JSON](blocks_live_20261014.json)。

## 测试结果

宿主模拟直接编译执行原始 `mini_python.c` 与 `klq_runtime.c`，仅替换时间、GPIO、外接设备和显示边界。22 组通过，共 164175 次断言，覆盖 26 项映射。支持电机的测试替身验证调用参数、计时结束停机、双端口动作和第二路启动失败回滚；不支持的测试替身验证错误退出。

实板通过 USB COM123 顺序下载测试 Python 到 RAM，41 项功能断言通过。CS100A 在端口 2、有效样本状态 1；当前 SC7 姿态满足方向 0 与 3，方向 1 与 2 保持等待。所有等待测试的 USB STOP 应答均小于 0.5 s，本轮最长约 16 ms；该值是电脑端请求应答时间，不是物理电机停车时间。

## 重复执行

无硬件模拟：

```powershell
python tools/test_blocks_sim.py --report build/blocks_sim.json
```

需要完整 GCC/Clang 或 VC 编译器，可用 `--cc` 或 `KLQ_SIM_CC` 指定。本机 ST MinGW GCC 缺少汇编器/链接器，实际采用 VC98 12.00.8168，`/TP /W3 /WX /O2` 加整数宽度 shim；生产 C 文件保持原样。C++ 语法模式的宿主结果不能替代 ARMCC 目标构建。当前板上镜像与已验收 ARMCC 镜像 SHA-256 相同：`1BE677DB4FD6854F60B6B8BC90BF1A46C4EFBB3282BF50ED453A47025F358ECF`，BIN 20412 B，map RO 20128 B、RW 26448 B。

实板接口测试：先停止占用机器人 CDC 的监测服务，然后运行：

```powershell
python tools/test_blocks_live.py --port COM123 --report build/blocks_live.json
python tools/status_dashboard.py
```

实板工具会覆盖现有 RAM 用户程序；它不写内部 Flash，但结束时通过软件复位返回引导再 RUN，以清空测试 RAM 程序。测试报告在重启前先保存；RESET/RUN 放在 8 秒上限的子进程中，避免 Windows CDC 重连时测试进程无限等待。退出函数在本轮单独验收成功，最终 `USER_STATE=0, USER_VALID=0, UI=1, PY_ERROR=0`。自动测试时不能触碰按键或改变板子姿态，否则当前状态条件可能改变。

退出工具另有 7 项离线故障注入全部通过：INFO/固件确认/快照失败、STOP/关闭串口/保存报告/清理同时失败时仍尝试清理并保留原始错误；USB 子进程超时或非零退出后仍验证预期 INFO；COM 变化后 RUN 使用新引导端口。可运行 `python -B tools/test_block_tool_cleanup.py`，该工具替换串口与子进程调用，不接硬件。

## 尚待实物验收

电机测试成功依赖模拟驱动，生产 `external_port_motor()` 仍未接入设备协议，不能据此宣布电机已动作或已物理停机。后续接入子板协议时需验证持续控制/保活与 250 ms 子板失联保护、方向和实际停车。红外条件仅验证明确报告不支持。PC3 实物按下/释放及电平、SC7 安装方向、点阵每个图案的实际观感和超声精度仍需分别确认。
