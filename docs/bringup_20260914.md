## 当前观测

冷启动后 SWD 读到 CPU 正常运行、无 CFSR/HFSR 故障。USB CTRL=`0x9C08`、ADDR=`0`；PA12 输入为高、PA11 为低，未见主机总线 RESET。Windows 仅显示 DAPLink 的 COM92，没有机器人 USB 串口。

正在区分 USB 软件初始化、数据线/接口连接与实际硬件问题。参考原理图 `KLQ2_V1.1.pdf` 中的 R6 标为 D+ 上拉至 5V，Type-C 两组数据线还需对照 PCB 和实物核实；图纸是否与本板完全一致尚未确认。

## 已做的软件调整

- USB 端点缓冲区使用不重叠的 PMA 地址。
- SDK suspend 处理改为非阻塞。
- 初始化前拉低 D+ 300 ms，USB 模拟部分上电等待 2 ms，控制器准备好后释放 D+。
- DAP 烧录脚本补充 `reset_and_halt()`。此前直接在原固件运行状态下启动 Flash 算法曾产生 HardFault；使用 pyOCD load 成功恢复并读回校验。脚本修订后的完整重写流程还需实测。
